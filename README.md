# Word Memory Game

A simple flashcard-based web application built with Vue 3 and Vite, designed to help users memorize new vocabulary. This project was developed as a hands-on practice application to master Vue 3 core concepts and features.

## 🚀 Features

* **Dynamic Flashcards:** Interactive cards that flip on click to show translations.
* **Score System:** Real-time score tracking based on successful or failed word retention.
* **Smart UI Layout:** Responsively arranged card grid with an adaptive layout that shifts core elements dynamically during gameplay.
* **External API Integration:** Card data (words and translations) is fetched dynamically from a separate backend service.

## 🛠️ Tech Stack

* **Frontend:** Vue 3 (Composition API)
* **Build Tool:** Vite
* **Styling:** CSS Grid & Flexbox (Scoped CSS)
